## 📌 Sobre o projeto

O projeto **Consumo Consciente de Água** é um programa desenvolvido
em Python para classificar o perfil de consumo de imóveis.

O sistema solicita o tipo de imóvel e o consumo mensal de água em
metros cúbicos. Depois, verifica as regras de negócio e apresenta uma
mensagem educativa ao usuário.

## 🎯 Objetivo

- Classificar o consumo de água de casas e apartamentos.
- Identificar consumos econômicos, moderados e excessivos.
- Informar quando deve ser aplicada a tarifa comercial.
- Incentivar atitudes de economia e prevenção de vazamentos.

## ▶️ Como executar

1. Instale o Python 3 em seu computador.
2. Faça o download ou clone este repositório.
3. Abra o terminal dentro da pasta do projeto.
4. Execute o comando:

```bash
python app.py
```

Em alguns sistemas, pode ser necessário utilizar:

```bash
python3 app.py
```

5. Informe o tipo de imóvel e o consumo mensal solicitado pelo programa.

## 🧪 Exemplos de classificação

| Tipo de imóvel | Consumo | Resultado |
|---|---:|---|
| Comercial | Qualquer valor | Tarifa comercial aplicada |
| Apartamento | Menor que 10 m³ | Consumo econômico |
| Casa ou apartamento | Até 25 m³ | Consumo moderado |
| Casa ou apartamento | Acima de 25 m³ | Consumo excessivo |

## 🌱 Conscientização ambiental

Economizar água ajuda a preservar os recursos naturais e a reduzir
desperdícios. Também é importante verificar torneiras, registros,
descargas e tubulações para identificar possíveis vazamentos.
