# 🎛️ Sistema de Reservatório Simples

Este é um script em **Python** desenvolvido para monitorar níveis de reservatórios e emitir alertas visuais formatados no terminal, utilizando a biblioteca **Colorama** para melhorar a legibilidade dos avisos.

---

## 🚀 Tecnologias Utilizadas

- **Python 3.x**
- **Colorama** (Biblioteca para estilização de texto no terminal)

---

## 📦 Instalação e Execução

Para rodar este projeto localmente, certifique-se de ter o Python instalado em sua máquina e siga os passos abaixo:

### 1. Clonar o Repositório
```bash
git clone https://github.com
cd sistema-reservatorio
```

### 2. Configurar o Ambiente Virtual (Recomendado)
```bash
# Criar o ambiente virtual
python -m venv venv

# Ativar o ambiente virtual
# No Windows:
venv\Scripts\activate
# No Linux/macOS:
source venv/bin/activate
```

### 3. Instalar as Dependências
```bash
pip install colorama
```

### 4. Executar o Projeto
```bash
python main.py
```
*(Substitua `main.py` pelo nome real do seu arquivo principal script, caso seja diferente)*
